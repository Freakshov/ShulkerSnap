  Shulker kutularını ve sandıkları açtığınız an içindeki tüm eşyaları salisesinde envanterinize çeken, ardından ekranı otomatik kapatan hafif ve ultra hızlı bir Fabric modu.

---

### 📌 Desteklenen Sürümler
- **Mod Yükleyici:** Fabric Loader (Client-Side / Sadece sizde olması yeterli)
- **Minecraft Sürümleri:** `1.20.x` ve `1.21.x` arası tüm sürümler
  - 1.20, 1.20.1, 1.20.2, 1.20.4, 1.20.6
  - 1.21, 1.21.1, 1.21.2, 1.21.3, 1.21.4

---

### 🚀 Neler Yapıyor?
- **Tüm Shulker Renkleri:** 16 boyalı shulker ve renksiz shulker kutularının hepsiyle çalışır.
- **Sandık & Fıçı Desteği:** Tekli/çiftli sandıklar, fıçılar, tuzaklı sandıklar ve ender sandıkları da anında boşaltır.
- **Işık Hızında Çekim:** Eşyalar sunucudan geldiği mikrosaniyede Shift-Click ile envantere aktarılır; kimseden yavaş kalmazsınız.
- **Otomatik Kapatma:** Eşyalar çekildiği an arayüz kapanır, koşmaya devam edebilirsiniz.
- **Anti-Cheat Ayarı:** Katı sunucularda kick yememek için gecikme (ms) ayarlayabilirsiniz.
- **Oyun İçi Tuş Değiştirme:** Menülerle uğraşmadan sohbete `/shulker keybinds` yazıp istediğiniz tuşa basarak kısayolu değiştirebilirsiniz.
- **Çoklu Dil:** Türkçe, İngilizce ve İspanyolca dillerini destekler.

---

### 🎮 Komutlar ve Tuşlar

| Tuş / Komut | Açıklama |
| :--- | :--- |
| **`J` Tuşu** | Modu anında açar veya kapatır *(Değiştirilebilir)* |
| `/shulker keybinds` | Tuş değiştirme modunu açar; ardından basacağınız ilk tuş yeni kısayolunuz olur *(ESC iptal eder)* |
| `/shulker toggle` | Modu komutla açar / kapatır |
| `/shulker delay <ms>` | Çekme gecikmesini ayarlar (`0` ms anında çeker) |
| `/shulker autoclose` | Eşyalar çekilince ekranın otomatik kapanmasını açar / kapatır |
| `/shulker chests` | Sandık ve fıçıların çekilmesini açar / kapatır |
| `/shulker shulkers` | Shulker kutularının çekilmesini açar / kapatır |
| `/shulker lang <tr\|en\|es>` | Dili değiştirir |
| `/shulker status` | Mevcut tüm ayarları sohbette gösterir |

### 📦 Kurulum
1. Bilgisayarınızda **Fabric Loader** ve **Fabric API** kurulu olsun.
2. `ShulkerSnap-1.0.0.jar` dosyasını `.minecraft/mods` klasörüne atın.
3. Oyunu başlatın, hepsi bu kadar!
